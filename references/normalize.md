# NORMALIZE

This guide is for optional, explicitly requested reference-backed work. The default
self-contained `SKILL.md` does not load this guide or call these tools.

1. Identify passage type, audience, supplied glossary, and protected strings.
   Read relevant generated rules, including vocabulary rules and the applicable
   writing section. For counts, retrieve section 8 as well as the length rule.
2. Rewrite using the retrieved evidence. Preserve technical meaning, actions,
   dependencies, and level of obligation. Keep ambiguity visible; do not resolve
   an unknown actor, value, or condition by inventing one.
3. Query dictionary candidates in context. Check meaning, part of speech, listed
   forms, and help text. Check technical nouns and verbs against their rule
   categories and domain evidence. Keep a short list of unresolved terms.
4. Run the deterministic validator on the revision, with the applicable passage
   type. Review its candidates and then assess the semantic rules it cannot test.
5. Return the revised text as the primary result. If useful, include a concise
   change summary, rule/page citations, and remaining questions. Say the text was
   reviewed against the retrieved rules; do not claim certified compliance.

Do not change a quoted label to make it look like STE. Do not create quotes or
hyphens merely to evade a word limit. Generic technical terms require contextual
review just as domain-specific terms do.
